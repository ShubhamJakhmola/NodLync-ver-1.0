# Setup Guide

## 1) Install the extension

- Install the NodLync Chrome extension only if you need browser traffic capture or debugging.
- Pin it to the toolbar for quick access.

## 2) Create your workspace

- Sign up and create a workspace.
- Choose a project name that matches your environment (prod/staging).

## 3) Start capturing data

- Open your app in Chrome.
- Trigger flows you want to measure (login, checkout, search).

## 4) Verify data quality

- Confirm provider requests work with your own API key.
- Confirm captured traffic appears only for the flows you intentionally test.
